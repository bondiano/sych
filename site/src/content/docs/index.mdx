## How it reviews

<CardGrid>
	<Card title="Pinned snapshot" icon="seti:git">
		Reads Git objects only (no work tree, hooks or filters) and pins the target tip, diff base and
		head. Policy comes from the target tip, never from the reviewed head.
	</Card>
	<Card title="Obligations, not vibes" icon="list-format">
		A deterministic planner turns rules into obligations. The reducer accepts `SUPPORTED` only with
		complete evidence of an acceptable kind.
	</Card>
	<Card title="Facts before models" icon="magnifier">
		Semantic facts from pinned language servers, syntax facts, pinned linters and CI reports bound to
		the tested commit.
	</Card>
	<Card title="Bounded models" icon="setting">
		Role routing with bounded fallback. A cost upper bound is checked before every call, and a durable
		ledger records the charge after it.
	</Card>
	<Card title="UNKNOWN instead of silence" icon="warning">
		Whatever cannot be shown with evidence stays UNKNOWN with a reason, and coverage says what was not
		reviewed.
	</Card>
	<Card title="GitHub App" icon="github">
		Verified webhooks, durable jobs, a summary with inline comments, finding lineage, waivers and a
		`/v1` API. Sych reviews its own pull requests.
	</Card>
</CardGrid>
